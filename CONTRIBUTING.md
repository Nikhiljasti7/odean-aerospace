# Contributing to Odean Aerospace 🤝

We welcome community contributions, architectural enhancements, and aerospace visualization upgrades to **Odean Aerospace**!

## How to Contribute

1. **Fork the Repository**:
   Click the **Fork** button at the top right of this repository.

2. **Clone your Fork**:
   ```bash
   git clone https://github.com/<your-username>/odean-aerospace.git
   cd odean-aerospace
   ```

3. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/orbital-simulation
   ```

4. **Commit Your Enhancements**:
   Ensure commits follow conventional commit standards:
   - `feat(...)` for new features
   - `fix(...)` for bug fixes
   - `docs(...)` for documentation updates
   - `style(...)` for formatting/styling adjustments

5. **Submit a Pull Request**:
   Open a PR against the `main` branch with a concise description of your changes and test validation screenshots.
